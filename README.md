#Ferris Invest

O Ferris Invest é uma aplicação Fullstack para gerenciamento de uma carteira de investimentos, desenvolvida como parte do desafio prático da plataforma DIO.me, no Santander Bootcamp 2026 – Rust AI Developer.

O projeto foi construído a partir do repositório-base disponibilizado pela Digital Innovation One e tem como objetivo aplicar, na prática, conceitos de desenvolvimento web com Rust, integrando API, banco de dados, autenticação e páginas HTML em uma única aplicação.


- Sobre o desafio

A aplicação permite cadastrar, consultar e atualizar ativos de investimento, além de realizar o cadastro e a autenticação de pessoas usuárias.

Durante o desenvolvimento, são trabalhados conceitos como:

criação de aplicações web com Rust e Axum;
organização de rotas e responsabilidades;
persistência de dados com PostgreSQL e SQLx;
cadastro, listagem e atualização de ativos;
cadastro e autenticação de usuários;
autenticação com cookies e JWT;
criação de páginas HTML com Askama;
execução do banco de dados com Docker;
testes das principais operações da aplicação.


- Objetivo do projeto

O objetivo deste projeto é compreender o funcionamento de uma aplicação Fullstack desenvolvida em Rust e evoluir o código-base por meio da implementação de melhorias próprias.

Entre as possíveis evoluções estão:

melhoria do dashboard;
criação de formulários para cadastro e edição de ativos;
inclusão de novas informações sobre os investimentos;
cálculo do valor total da carteira;
melhoria das validações e mensagens de erro;
criação de novos testes;
aprimoramento da documentação.

- Aprendizados

Durante o desenvolvimento deste projeto, foi possível praticar a criação de uma aplicação web completa com Rust, incluindo integração com banco de dados, criação de rotas, autenticação de usuários, renderização de páginas HTML e organização das responsabilidades da aplicação.

Além disso, o desafio proporcionou experiência com leitura e compreensão de um projeto existente, implementação de melhorias e documentação das alterações realizadas.

Projeto desenvolvido como parte do Santander Bootcamp 2026 – Rust AI Developer, promovido pela DIO.me.
